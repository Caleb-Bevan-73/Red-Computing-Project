Ryzen: documented 65 W TDP; app uses a clearly labeled 100 W CPU planning
allowance, NOT a claimed manufacturer maximum. Stock settings, PBO off.
Intel: documented maximum turbo power 181 W, assuming Intel power limits.
RX 7800 XT reference: 263 W board power, minimum 700 W PSU and >54 A +12 V,
two PCIe 8-pin GPU inputs. RTX 4070 SUPER reference: 220 W graphics power,
minimum 650 W PSU, two 8-pin cables through supplied adapter OR >=300 W native
PCIe Gen 5 cable. Selected PSUs use the latter path for this GPU.

App planning target = max(GPU vendor PSU guidance,
ceil((CPU budget + GPU board power + 100 W other parts) * 1.25)).
100 W covers the motherboard, one RAM kit, one drive, fans and modest USB load;
25% is an explicit planning reserve, not a transient-load measurement.
Result: 700 W for either CPU with Radeon; 650 W for either CPU with GeForce.
Both 750 W and 850 W paths meet those assumptions and documented +12 V guidance.
PSU suitability remains conditional: overclocking, changed power limits, partner
GPU variants and additional hardware need a new assessment.

Architecture and persistence
BuildConfiguration is the authoritative value for all six selections.
MyBuildsViewModel owns actions/state; PartOption presents candidate feedback.
BuildCompatibility is a reusable stateless evaluator. Models hold specifications;
views render options, detail links and status text. Known incompatible candidate
selections are rejected in the view model as well as disabled in the UI.
Existing selections are never removed because of compatibility results.
BuildStore continues to encode the same UserDefaults workspace and UUID snapshots.
Custom decoding defaults absent new selection fields to empty strings, preserving
version-one saves. Save, Save as New, switching and cancellation use the same flow.
Comparison remains CPU/GPU-only; no invented benchmarks for new categories.

Limits
No complete-PC guarantee: exact RAM kit QVL/profile stability, installed BIOS,
case/PSU mounting, physical GPU/cable clearance, CPU cooling and front-panel
connections remain unverified. The one-drive path assumes the recommended slot
is free. Empty/missing specifications return unknown, never a passing result.
